# Kasvivahti
Yksinkertainen selainpohjainen sovellus huonekasvien kastelun seurantaan.

## Käyttöohjeet
1. Lataa `index.html`-tiedosto.
2. Avaa tiedosto missä tahansa modernissa selaimessa (tuplaklikkaa tiedostoa).
3. Sovellus on heti käyttövalmis. Erillistä palvelinta tai asennusta ei tarvita. Data tallentuu selaimesi LocalStorageen.
